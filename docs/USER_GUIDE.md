# Using Presenteriyaki

## Presenting

Open a PDF from the File menu or drag it into a window. The presenter window shows
the current slide, next slide, notes, timer and thumbnails. The audience window
shows the presentation.

The opening screen has an **Open PDF…** button. **File → Open Recent** reopens
previous decks. The next-slide preview says **End of presentation** on the last page.

Choose **View → Audience display** to select a screen. Press **F5** for fullscreen
or double-click the audience window to fill only that screen. **Esc** returns to
windowed mode; **X** swaps the displays.

| Key | Action |
|---|---|
| ← / → | Previous / next slide |
| Home / End | First / last slide |
| Number, then Enter | Jump to a page |
| T | Start / pause the timer |
| Shift+T | Switch between clock and timer |
| Z | Reset the timer |
| . | Blackout |
| B | Whiteboard |
| L | Cycle pointer, laser and spotlight |
| ? | Switch between quick help and all shortcuts |

Click the clock to start or pause the timer. **Timer → Set duration** sets a
countdown; use zero for elapsed time. Changing the duration preserves elapsed
time. The label below the clock shows whether the timer is running or paused.

## Notes

Presenteriyaki reads PDF text annotations, embedded notes and matching `.pdfpc`
files placed beside the PDF. Beamer's notes-on-right layout is also supported;
choose it under **View → Notes layout** if needed.

Use **+ / −** to adjust note size and **0** to reset it. Notes stay on the presenter
screen.

## Drawing

Drag to draw, or hold **Shift** to begin drawing immediately. Press **C** to choose
a color and opacity. **Alt-drag** selects strokes; **Shift-drag** moves the
selection and the scroll wheel resizes it. **Delete** erases the selection or last
stroke, and **E** clears the selection or all visible ink.

Hold **Ctrl/⌘** while scrolling to zoom, or while dragging to pan. **Ctrl/⌘+0**
resets the view. Drawing does not change the PDF file.

## Media and camera

Click a media link in a slide or choose **Media → Open video or audio**. **Space**
plays or pauses media; **< / >** steps frames. **Shift+M** expands the media view.

**V** toggles the camera and **Shift+V** expands it. Use **Media → Camera appearance**
to adjust the inset's size, opacity and corner, and **Media → Choose camera** to
select a device.

On a timed slide, **Space** pauses automatic playback. **View → Automatic playback**
controls timed page changes and autoplay animations. Individual animation controls
are also available on the slide.

## Web content

Web links open in the audience window. Press **Esc** to return to slides.

Web pages can play H.264/MP4 video. Your camera inset stays above the web content;
**F5** toggles fullscreen. Use the presenter window's zoom controls to adjust web
content, and **0** to reset its zoom.

Websites may require login or restrict playback in embedded browsers. Local video
and audio files also open through **Media → Open video or audio**.
